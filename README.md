# Mem-World

Project page for Memory-Augmented Action-Conditioned World Model for Robot Manipulation (CoRL 2026 Oral).

Paper: https://arxiv.org/abs/2606.18960

This repository contains a static website. Enable GitHub Pages from the main branch and the repository root. No installation or build step is required.

The method section includes the expanded initialization, retrieval, and update figures from the oral presentation.
